CONCEPT

タイガースファンをつなぐアプリ

応援に必要な情報と、ファン同士の一体感をひとつに。

「応援する時間」を、もっと身近に。

試合日程を確認したり、応援メッセージを投稿したり。球場に行けない日でも、アプリを開けばチームを応援する仲間の熱気を感じられます。初めて応援する人にも使いやすい、シンプルな画面を目指しました。

かんたん操作応援を共有試合情報

ABOUT THIS PROJECT

学生のアイデアから生まれた、架空のアプリ。

この作品は、スポーツ観戦をもっと楽しむ方法を考え、企画・画面設計を行った学生作品のサンプルです。使う人の立場に立ち、必要な情報を見つけやすくすることを大切にしました。

作品データ

  • 作品名：タイガース応援アプリ
  • ジャンル：スポーツ・ファン向けアプリ
  • 制作：IT系専門学校 学生作品（架空）
  • 担当：企画・UIデザイン・Web制作
  • 使用技術：HTML / CSS / JavaScript（想定）

制作で工夫したポイント

スマートフォンでの閲覧を意識したレスポンシブデザインを採用。色やアイコンで情報を整理し、初めて使う人でも直感的に内容を把握できる構成にしました。

今後のアップデート案

プッシュ通知、選手情報の詳細表示、応援メッセージへのリアクション機能など、ファン同士の交流をさらに広げる機能を検討しています。
